SinkTrace

Municipal water loss tracker — traces inconsistencies across usage data, billing, and infrastructure.

About This Project

SinkTrace is a solo-built diagnostic tool that simulates pressure behavior in municipal water systems. It tracks junction activity, identifies silent leaks and flags reversed flow using dynamic logic. The interface shows a responsive grid map and logs pressure changes in real time. The goal is to make invisible infrastructure problems easier to see and understand.

How It Was Built

This build uses HTML5, modular JavaScript and a clean DOM rendering engine to visually display and classify water fixtures based on user input. It supports interactive labeling and icon mapping with a lightweight footprint.

FAQ

Q: Does this require internet access?
A: No. SinkTrace runs entirely in your browser with no data saved or sent.
